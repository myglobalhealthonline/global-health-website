# Image delivery changes — 2026-09-11

Deployed to Production; existing public media optimization completed successfully.

- Audited all 134 bundled images (3,362,230 bytes). Recompressed 11 PNGs losslessly, saving 37,463 bytes. The script verified identical decoded RGBA pixels and dimensions before every write. Retained other files where recompression would increase size, lose quality, or replace vector/animated formats.
- Product cards and lab-test heroes now use Next Image with responsive sizes. The login background now uses the existing optimizer. Existing AVIF/WebP negotiation remains enabled; added a 3840px candidate for larger, high-density screens.
- Public article and page-body images now receive responsive optimizer URLs, lazy loading and asynchronous decoding. Authored responsive sources and eager loading remain respected. Unknown external sources and protected routes are not sent through the public image cache.
- The shared upload converter retains original pixel dimensions, corrects camera orientation, skips animation and images beyond WebP's dimension limit, and only replaces an upload when the result is smaller. Compression remains WebP quality 82, which is lossy; retaining dimensions is not a promise of identical pixels for uploaded photos.
- Private medical/identity documents, chat attachments, tracking pixels, original editing previews, SVGs and existing optimized picture sources retain their appropriate delivery paths.
