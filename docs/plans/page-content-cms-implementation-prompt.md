## PART A — BACKGROUND: what this product is and why this task exists

### A.1 The product

Global Health is a multi-country telemedicine website. Public URLs are country- and language-scoped:

```
/{countrySlug}/{lang}/...        e.g.  /ie/en/gp-appointment   /cz/cs/gp-appointment
```

Supported countries (lowercase codes in DB): `ie` (Ireland), `cz` (Czechia), `pt` (Portugal), `es` (Spain), `ro` (Romania), `br` (Brazil). Each `Country` row has a `defaultLocale` (e.g. CZ→CS, PT→PT, IE→EN) and a list of supported locales. Country = URL segment only (no country cookie; the `gh_locale` cookie stores language only).

Each country has a "GP hub" landing page at `/{country}/{lang}/gp-appointment`. The URL is a rewrite (see `frontend/next.config.ts:206-326`); the actual page component lives in the folder:

```
frontend/app/(site)/[country]/[lang]/general-consultation/page.tsx
```

### A.2 The problem we are solving

The Ireland GP hub page shows five rich marketing/legal sections that other countries do NOT show:

1. **Intro** — a positioning paragraph under the hero ("What this is")
2. **Who it's for** — a checklist-card section listing 13 conditions the service treats
3. **Why choose Global Health** — a card grid of 6 selling points
4. **FAQ** — an accordion of 8 question/answer pairs
5. **Medical disclaimer** — legally signed-off paragraphs

Root cause (already audited and confirmed — do not re-audit): these sections come from a **hardcoded TypeScript file**, `frontend/lib/content/ireland-service-content.ts`, whose lookup `getGpHubContent(countryCode)` only returns content for `"ie"`. Every other country gets `null`, and the page hides each section when content is null. This was a deliberate legal gate (the Irish copy names the Irish Medical Council, Irish prices, Irish sick-note law, Irish emergency number) — the copy can NOT simply be reused for other countries.

Separately, the admin portal has an old CMS section called "Page content" at `/admin/pages` (backed by the Prisma model `ContentPage`). It lets admins override hero title/subtitle, a rich-HTML body, CTA and SEO fields per country×page×locale. **The owner does not use it and wants it gone.**

### A.3 The goal (owner's words, paraphrased)

Replace the unused "Page content" admin section with a NEW structured page-content editor where:

- The Ireland hub sections (intro, Who it's for cards, Why choose cards, FAQ, disclaimer) are stored **in the database per country**, not hardcoded.
- Admins open the portal, pick a country and a page, and edit those sections' content — **the public UI/design/cards/colors stay EXACTLY the same for every country; only the text content differs per country.**
- Every section has an **ON/OFF toggle** per country, so a market can hide a section it has no approved copy for.
- Multiple languages per country are edited via **language tabs** in one editor.
- Ireland's existing approved copy is migrated into the DB **verbatim** and the Ireland page must look **pixel-identical** before/after.
- Draft copy for the other countries is generated by the agent for owner review (kept invisible until published).

### A.4 Success criteria in one sentence

An admin can toggle on "Why choose Global Health" for Czechia, type 6 card texts in Czech and English, hit Publish — and the Czechia GP hub instantly shows the identical card grid Ireland has, in the visitor's language, while Ireland's page has not changed by a single pixel.

Add to `backend/prisma/schema.prisma`:

```prisma
model PageContent {
  id        String        @id @default(cuid())
  countryId String
  pageKey   PageKey
  status    PublishStatus @default(DRAFT)
  isActive  Boolean       @default(true)

  // Non-translatable config
  heroImagePath String?
  ogImagePath   String?
  ctaHref       String?

  // Per-section visibility toggles. Public renders a section only when
  // its toggle is ON *and* resolved content is non-empty *and* the row
  // is PUBLISHED + active. Toggle OFF = intentionally hidden;
  // toggle ON with empty content = "not configured" (hidden + admin warning).
  showIntro      Boolean @default(false)
  showWhoFor     Boolean @default(false)
  showWhyChoose  Boolean @default(false)
  showFaq        Boolean @default(false)
  showDisclaimer Boolean @default(false)
  showBody       Boolean @default(false)

  country      Country                  @relation(fields: [countryId], references: [id], onDelete: Cascade)
  translations PageContentTranslation[]
  createdAt    DateTime                 @default(now())
  updatedAt    DateTime                 @updatedAt

  @@unique([countryId, pageKey])
}

model PageContentTranslation {
  id            String     @id @default(cuid())
  pageContentId String
  locale        LocaleCode

  // Hero copy (overrides the page's i18n defaults, exactly like old ContentPage did)
  heroTitle    String?
  heroSubtitle String?
  ctaLabel     String?

  // Structured sections — shapes mirror GpHubContent so the public
  // components receive identical props to today's hardcoded IE copy.
  intro                String? // ServiceIntro body (plain text/short paragraph)
  whoForTitle          String?
  whoForIntro          String?
  whoForItems          Json?   // string[] — one entry per checklist card
  whyChooseTitle       String?
  whyChooseItems       Json?   // string[] — one entry per card
  faq                  Json?   // Array<{question: string; answer: string}>
  disclaimerParagraphs Json?   // string[] — full disclaimer, one entry per paragraph
  disclaimerShort      String?

  body String? // sanitized rich HTML (RichBodySection)

  seoTitle       String?
  seoDescription String?

  pageContent PageContent @relation(fields: [pageContentId], references: [id], onDelete: Cascade)
  createdAt   DateTime    @default(now())
  updatedAt   DateTime    @updatedAt

  @@unique([pageContentId, locale])
}
```

- **Single exported visibility helper** (unit-test this exhaustively):

```ts
export function computeSectionVisibility(row: PageContentBase, t: MergedTranslation) {
  const nonEmpty = (s?: string | null) => !!s && s.trim().length > 0;
  const list = (v: unknown): string[] => Array.isArray(v) ? v.filter((x) => typeof x === "string" && x.trim()) : [];
  return {
    intro:      row.showIntro      && nonEmpty(t.intro),
    whoFor:     row.showWhoFor     && list(t.whoForItems).length > 0,
    whyChoose:  row.showWhyChoose  && list(t.whyChooseItems).length > 0,
    faq:        row.showFaq        && Array.isArray(t.faq) && t.faq.length > 0,
    disclaimer: row.showDisclaimer && (list(t.disclaimerParagraphs).length > 0 || nonEmpty(t.disclaimerShort)),
    body:       row.showBody       && nonEmpty(t.body),
  };
}
```
